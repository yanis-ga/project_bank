# project_bank

## Description

* In the solution WpfBankProject on dev branch :

  A project to analyze the balance and transaction details of an account by reading MT940 files with a WPF interface.


## Getting Started

### Installing

* Git clone the project and run into your IDE : VS Code Community

### Executing program

* Go to dev branch and start the program to access the application
* Import a MT940 file from your computer
* After that, you can view the results and click on a line to see the row details section
* And lines containing errors will be displayed in red
